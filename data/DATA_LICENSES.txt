XP12 Forest Tweak - hedge map data files and their licenses
===========================================================

The hedge map files (hedgerow_map_*.dat) contain only the outlines and the type
(hedge / hedgebank, tree row, copse) of the official data below, converted into a
compact format. The data files are NOT under the tool license (CC BY-NC-SA 4.0):
each one keeps the license of its source. Changes for all files: only geometry and
type kept, all other attributes removed, coordinates converted to ETRS89 / UTM 32N
(EPSG:4647) rounded to 0.1 m, written in a compact binary format. Denmark: stone
walls (Stendige = Ja) left out. Agricultural data: only hedges (HK), tree rows (BR)
and field copses (FH) kept. In X-Plane the data is turned into forest strips and
tree rows on your computer.
